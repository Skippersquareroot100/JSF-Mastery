Check your Tomcat console to see the JSF lifecycle phases.
📊 The 6 Phases of JSF Lifecycle (on form submit):
  1. RESTORE_VIEW → Rebuild component tree from saved state
  2. APPLY_REQUEST_VALUES → Extract submitted values from HTTP request
  3. PROCESS_VALIDATIONS → Validate all input fields (required, length, regex, etc.)
  4. UPDATE_MODEL_VALUES → Update bean properties (setName() called here!)
  5. INVOKE_APPLICATION → Execute action methods (submit() called here!)
  6. RENDER_RESPONSE → Generate HTML and send back to browser
On initial page load (GET), only phases 1 and 6 execute.
